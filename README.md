# Prop Firm Hedge Cost Calculator

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Inputs:
- Cost per account
- Number of accounts
- Drawdown
- Profit target
- Consistency rule

Outputs:
- Day-by-day hedge TP
- Day-by-day hedge SL
- SL ratio
- Total hedge losses
- Total worst-case cost
